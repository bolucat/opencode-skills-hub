# opencode-skills-hub

AI Agent skills 集合仓库，只在 Opencode 上测试过，其他 Agent 不保证完全适用。

## 目录结构

| 目录 | 说明 |
| --- | --- |
| `anthropics-skills` | 来自 [anthropics/skills](https://github.com/anthropics/skills) |
| `Jeffallan-claude-skills` | 来自 [Jeffallan/claude-skills](https://github.com/Jeffallan/claude-skills) |
| `zhaoxuya520-reverse-skill` | 来自 [zhaoxuya520/reverse-skill](https://github.com/zhaoxuya520/reverse-skill) |
| `own` | 自用的一些 skills |

## 使用

`git clone --depth=1 https://github.com/bolucat/opencode-skills-hub opencode-skills-hub`

复制需要使用到的 skill 文件夹，到 `/.config/opencode/skills` 目录

如果暂时用不到这个类型的 skill，不建议进行安装，这会增加不必要的 token 消耗
